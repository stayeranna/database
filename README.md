Автоматизация работы театральной кассы

Информация о спектаклях: состав актеров, расписание показа (афиша) на текущий год, длительность, стоимость билетов для: партера, амфитеатра, галёрки, ложи бельэтажа;
Информация о билетах: кол-во проданных/непроданных билетов по типам на конкретный показ спектакля;
Реализовать:
- вывод информации об актерах на заданный спектакль
- выдача информации о свободных билетах в соответствии с требуемой ценой и типом мест;
- поиск наиболее/наименее популярныйх спектаклей
- поиск наиболее/наименее занятых актеров
-подсчет выручки театра от продажи билетов
